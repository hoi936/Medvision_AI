# Mục tiêu của phần AI

# 1. Mục tiêu của phần AI

MedVision không chỉ có một model duy nhất.

Về lâu dài chúng ta có thể có:

```
                    MEDVISION AI
                         │
          ┌──────────────┴──────────────┐
          ↓                             ↓
    Classification                 Localization
          │                             │
          ↓                             ↓
   DenseNet / CBAM                Bounding Box
          │
          ↓
    14 X-ray findings
```

Model hiện tại của chúng ta tập trung vào:

> **Multi-label chest X-ray abnormality detection**
> 
> 
> Phát hiện nhiều bất thường trên cùng một ảnh X-quang.
> 

Ví dụ một ảnh có thể đồng thời:

```
Cardiomegaly       0.86
Pleural effusion   0.72
Lung Opacity       0.61
Atelectasis        0.18
Pneumothorax       0.04
```

Đây là **finding detection**, chưa phải kết luận bệnh cuối cùng.

# 6. Bước 1 — Đọc DICOM

Ảnh VinBigData không phải JPG thông thường.

Là:

```
.dcm
```

Chúng ta dùng:

```
pydicom
```

để đọc.

Pipeline:

```
DICOM
 ↓
Pixel Array
 ↓
Metadata
 ↓
MONOCHROME1 / MONOCHROME2
 ↓
Normalize
```

Đây là phần rất quan trọng vì DICOM có thể có:

```
BitsStored = 10
BitsStored = 12
BitsStored = 16
```

và:

```
MONOCHROME1
MONOCHROME2
```

Nếu xử lý sai thì model học từ ảnh sai.

---

# 7. Bước 2 — Xử lý MONOCHROME

Ví dụ:

```
MONOCHROME2
```

thì thông thường pixel intensity được hiểu theo hướng:

```
giá trị thấp → tối
giá trị cao → sáng
```

Trong khi `MONOCHROME1` cần đảo intensity.

Vì vậy pipeline phải kiểm tra:

```
ifPhotometricInterpretation=="MONOCHROME1":image=image.max()-image
```

Sau đó mới normalize.

# 8. Bước 3 — Normalize ảnh

Ảnh DICOM có thể có intensity rất lớn.

Ta đưa về:

```
0 → 1
```

hoặc chuẩn hóa theo ImageNet trước khi đưa vào DenseNet.

Cuối cùng:

```
DICOM
 ↓
float32
 ↓
normalize
 ↓
resize 384×384
 ↓
3 channels
```

# 9. Tại sao 3 channels?

X-quang thường là grayscale:

```
H × W
```

DenseNet pretrained ImageNet mong muốn:

```
3 × H × W
```

Vì vậy ta chuyển:

```
Gray
 ↓
RGB-like
 ↓
3 × 384 × 384
```

Không phải biến ảnh X-quang thành ảnh màu thực sự.

Chỉ là:

```
R = Gray
G = Gray
B = Gray
```

để tương thích kiến trúc pretrained.

# 14. Bước 8 — Majority Vote

VinBigData có 3 radiologist.

Ví dụ:

```
Cardiomegaly

Doctor A → 1
Doctor B → 1
Doctor C → 0
```

Ta dùng:

```
2/3 → Positive
```

Nếu:

```
0
0
1
```

→ Negative.

Nếu:

```
1
1
1
```

→ Positive.

Đây là lý do chúng ta tạo:

```
Majority ≥ 2
```

Nhưng phải nhớ:

> Majority vote là nhãn nghiên cứu được tổng hợp từ annotator, không phải ground truth tuyệt đối.
>

# 17. Loss function

Vì là multi-label:

```
BCEWithLogitsLoss
```

Binary Cross Entropy cho từng class.

Tổng quát:

```
Loss =
loss(class 0)
+
loss(class 1)
+
...
+
loss(class 13)
```

Nhưng dataset mất cân bằng rất mạnh.

Ví dụ:

```
Cardiomegaly       hàng nghìn
Pneumothorax       chỉ vài chục
Atelectasis        rất ít
```

Nếu không xử lý:

```
Model học class phổ biến
↓
bỏ qua class hiếm
```

# 18. Pos Weight

Chúng ta đã tính:

```
pos_weight = negative / positive
```

Ví dụ:

```
Pneumothorax
```

rất ít positive.

Nên:

```
pos_weight rất lớn
```

Nhưng giá trị quá lớn gây training không ổn định.

Do đó chúng ta đã cap:

```
max pos_weight = 50
```

Ví dụ:

```
Atelectasis   238 → 50
Pneumothorax  259 → 50
```

# 24. Threshold

Sau sigmoid:

```
0.73
```

không tự động có nghĩa:

```

```

Ta cần threshold.

Ví dụ:

```
threshold = 0.5
```

thì:

```
0.73 > 0.5
→ positive
```

Nhưng mỗi class có thể cần threshold khác nhau.

Sau này có thể:

```

...
```

Tuy nhiên threshold phải được chọn trên validation/calibration phù hợp, không được tùy tiện.

# 25. Bước 11 — Confusion Matrix

Cho từng class:

```
                 Pred
             0          1

Actual 0    TN         FP

Actual 1    FN         TP
```

Từ đây tính:

```
Sensitivity = TP / (TP + FN)

Specificity = TN / (TN + FP)

Precision = TP / (TP + FP)

F1 = ...
```

# 27. Grad-CAM không phải bounding box

Đây là điểm chúng ta đã kiểm tra trên RSNA.

Grad-CAM:

> cho biết **vùng ảnh có ảnh hưởng đến quyết định của model**.
> 

Không đảm bảo:

> chính xác vị trí tổn thương.
> 

Vì vậy:

```
Grad-CAM ≠ lesion segmentation
Grad-CAM ≠ ground-truth bounding box
```

# 30. Bước 13 — CBAM

Sau baseline DenseNet121, chúng ta sẽ thử:

```
DenseNet121
      +
CBAM
```

CBAM:

> Convolutional Block Attention Module.
> 

Nó giúp model tập trung hơn vào:

```
Channel attention
+
Spatial attention
```

Có thể hình dung:

```
Feature Map
     ↓
Channel Attention
     ↓
Spatial Attention
     ↓
Refined Feature
```

Mục tiêu:

> xem attention có giúp detection và localization tốt hơn baseline hay không.
>
